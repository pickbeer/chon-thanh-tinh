# Chốn Thanh Tịnh

Trang web tĩnh tiếng Việt với không gian sân chùa, chính điện, thỉnh chuông và lời an lành.

## Đăng trang

Trang được xuất bản qua GitHub Pages bằng GitHub Actions.

## Lưu ý

Số người hiện diện hiện chỉ minh họa trong phiên trên trình duyệt; chưa có dịch vụ thời gian thực dùng chung.
